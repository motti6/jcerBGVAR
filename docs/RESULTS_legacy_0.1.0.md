## 被覆率と解釈

20回の既知同時GVARのMonte Carlo: IRF RMSE平均=0.007403、68%点別区間被覆率=0.6528、90%被覆率=0.9139、ゼロでない真のIRFの正符号確率平均=0.6272。
20反復は探索的。条件付きモデルの厳密なサンプリングは、外国変数に内生性があり得る同時DGPでの
名目被覆率を保証しない。識別済み政策因果効果の検証と混同しない。

## BGVARとの実務比較

BGVAR 2.7.0 MN, SV=FALSE, 100保持ドロー+100burn-in: 推定中央値  0.33秒、国別  0.29秒、世界構築  0.02秒、一般化IRF  0.76秒、符号識別+IRF  0.75秒。
MNIWとは事前分布・共分散モデルが異なる。単純な時間比やIRF差を同一モデルの高速化・近似誤差と呼ばない。
BGVARの公開APIでは符号探索とIRFが融合。符号探索だけの時間はNAのまま保存。
