# Phase 2以降の研究ゲート

Phase 1は条件付きMNIWを実装・検証する。Normal-GammaやSVとの違いを
計算精度の違いと呼ばない。`method="vb"` / `"hybrid"`は利用可能にしない。

Phase 2は、同一の階層Normal-Gamma事前分布と同一国別尤度について完全条件付き
分布を導出した参照MCMCが先行する。次に国別係数ブロックの共分散を保持する
structured qを設計し、ハイパーパラメータ更新とELBOを導出する。複数初期値、
単調性、独立数値微分、近似事後ドローのモーメントを検査する。
MCMCとの平均・分散・予測対数スコア・IRF・符号確率・68/90%被覆率を比較してから
公開APIへ追加する。現段階でNormal-Gammaの導出・実装・ELBO検証は未実施。

Phase 3はVBから米国・日本等のMCMC精緻化を選び、近似対象を明記する。
大規模性能は今回の段階別CPU実測で律速を確認した後、C++/ドロー並列化/GPUを検討。
現在の並列化は国別推定のみ。IRFは逐次Rフォールバック。
符号・順位制約の高度な探索や完全同時尤度は別の検証課題。
クロスプラットフォームCI、事前分布感度、より多数のMonte Carlo反復も残る。
