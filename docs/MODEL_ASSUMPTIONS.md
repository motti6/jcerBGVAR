# 統計モデルと検証範囲

- 各国の外国集計を所与とする条件付き回帰。国別誤差は独立、同時点外国変数は弱外生と仮定。
- 対象は国別MNIW事後分布の積。世界同時尤度のヤコビアンを含めた推定ではない。
- 国名・変数名を照合しE/Hを構築。国別変数集合は共通、サンプル行は整列済み。
  行名・時系列属性があれば一致を検査し、なければ呼出側が時間対応を保証する。
- 国別・変数別Wを指定可能。国の除外に伴う再正規化は明示的に指定し記録。
- 切片・国内各ラグ・同時点外国・外国各ラグの順に回帰係数行を保存。
- G0は一般に非対称。一般QR分解を再利用。Sigma_uは変換した共分散因子から構成。
- 数値的に特異・悪条件のG0は警告して除外。安定性はコンパニオン固有値で評価。
- 金利単位はメタデータ。自動スケーリングなし。GDP/物価の変換は利用者の選択。
- 一般化IRFは構造的Fed政策因果効果とは異なる。再帰IRFは明示的順序を要求。
- 符号制約は単一ショック、国別事後ドローごとの条件付きHaar回転。全世界の
  完全な構造事後分布や識別集合を推定するアルゴリズムではない。
- 同時方程式の合成DGPでは条件付き外国変数が誤差と相関し得るため、条件付き
  推定の理論的正しさとDGPに対する頻度論的被覆率は別に評価する。

## v0.1.1での改善

- 合成データの主検証は生成・推定とも同時点外国変数を除外する。G0=Iで、
  初期ラグを所与とする同時尤度も国別に因子化する。従来の同時点DGPは仮定違反診断として別表示。
- 被覆率の単位は独立に生成したデータセット。応答・ホライズンを独立反復とは数えない。
- 既存BGVARの推定結果には `jcer_irf_bgvar()` を使う。BGVARの事前・MCMC・
  共分散・安定性選択は変更しない。再帰は保存された縮約形ラグ行列を使う。
- BGVAR 2.7.0のGIRFの初期ベクトルは G0^{-1} Sigma_e e_j に比例する。
  世界縮約形一般化ショックの Sigma_u e_j とは区別する。主速度比較は前者で一致させる。
- MNIWとの差は後者の世界一般化ショックに揃えて測り、事前・分散モデル変更の影響として報告する。
